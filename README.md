## Usage Instructions

1. Add actual images to this directory
2. Update the HTML to reference the correct image paths
3. Ensure images are optimized for web (compressed, proper dimensions)
4. Use alt text for accessibility
5. Consider using responsive images with srcset for different screen sizes

## Image Specifications

- **Format**: JPG, PNG, or WebP
- **Hero Images**: 1920x1080px (16:9 ratio)
- **Service Images**: 800x600px (4:3 ratio)
- **Gallery Images**: 600x400px (3:2 ratio)
- **Team Photos**: 400x400px (1:1 ratio)
- **File Size**: Under 500KB for optimal loading
